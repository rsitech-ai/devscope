# DevScope audit, 2026-10-07

This pass compares against public `main` at `c4a3d2d`. It covers source review,
regression tests, native interaction, local build policy and independent review.
It is evidence for the specified paths, not proof that every possible host,
permission, automation or on-device model state is error-free.

## Review boundaries

- Scanner: bounded ps/lsof/ioreg execution, native metadata caches, exact argument
  evidence, process birth identity, directory carry-forward and normalization.
- Process actions: protected targets, stale/reused PIDs, live tree scope,
  confirmation, partial signal outcomes and post-action observation.
- Automation: inventory refresh/coalescing, source health, capability/ownership
  checks, command execution/cancellation, guarded filesystem I/O, recovery and
  manager/executor composition. Mutating native smoke uses a disposable fixture.
- Presentation: process scopes, filters/sorting, saved state, resource charts,
  settings/access, clipboard recovery and source warnings.
- Distribution: entitlements, notices, privacy manifest, exact bundle launch and
  current architecture. Local installation does not establish notarization.

The deterministic core still owns facts and action policy; optional Foundation
Models only enrich presentation. Foundation Models availability is checked and
the existing deterministic fallback remains available.

## Findings and changes

| Finding | Impact | Change / evidence |
| --- | --- | --- |
| Machine GPU values copied to every process history | Misleading process attribution | Per-process samples now leave GPU unavailable; process chip/chart omit it. Dashboard retains system GPU. |
| RSS multiplication and elapsed total can overflow | Invalid boundary input can trap | Guard finite/nonnegative metrics, conversion limit and total addition. Regression includes exact `Int64.max` elapsed time and overflowing total. |
| Endless oversized command continues until timeout | Unnecessary CPU and delayed failure | Overflow starts TERM/KILL process-group cleanup while pipes drain. Term-ignoring writer regression fails with outputLimitExceeded within four seconds rather than the ten-second deadline. |
| Synchronous scanner runs inside Swift tasks | Blocking waits occupy cooperative workers | Dispatch/continuation bridge used by process refresh, Settings access and automation process verification. Test asserts no current Swift task and no main thread inside the blocking closure. |
| Saved-item matching formats thousands of digest bytes and constructs file URLs | Main-thread work grows with process count | Direct lowercase hex encoding, no duplicate alias hash without CWD, lexical executable basename. Fixed hash vector preserves persisted key format. |
| Four-digit rail counts wrap inside a fixed 22-point width | Inventory total becomes hard to read | Keep the count on one line with intrinsic width and a 22-point minimum. |
| Release script forces SwiftPM's deprecated native backend | Swift 6.4 emits deprecation warnings | Use the toolchain's default backend for both build and binary lookup. |

The performance reproduction used a native app snapshot containing over 1,300
processes with one favorite and watched fixture. A sample of the main thread
showed category counting and saved-key matching dominated by hex formatting and
file URL construction. An optimized isolated benchmark of 6,500 SHA-256 key
encodings measured 1.171 seconds before and 0.009 seconds after, with identical
outputs. This isolates encoding cost; it is not an overall app speedup estimate.

## Limitations and remaining risk

- Some host LaunchAgent definitions are unreadable; the app reports partial
  source health. They were not changed by this audit.
- Background Items diagnostics report an administrator-approval limitation on
  the macOS 27 host. This does not prove background-item integration on other OS
  versions; the app leaves the state explicit.
- macOS logged App Intents connection errors for the existing and development
  bundles (`com.apple.linkd.autoShortcut`, Cocoa error 4097). The linkd service is
  running; Shortcuts integration remains unverified on this host.
- A command descendant that deliberately escapes its process group while
  retaining a pipe can outlive group cleanup. Review found no concrete production
  trigger in the fixed system-tool call sites; general arbitrary-job isolation
  is not claimed.
- Sandbox inspection, Apple Intelligence generation, notification delivery and
  all accessibility/system appearance combinations require separate evidence.
- A local ad-hoc signed build is not a notarized public release.
